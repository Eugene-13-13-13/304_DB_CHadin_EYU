# Лабораторная работа №1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite

## Описание структуры файлов данных

В каталоге 'Task01' на ходятся следующие файлы, полученные из исходного набора 'dataset'.

---

### `ratings.csv`
Файл содержит оценки пользователей фильмам.  
**Формат:** CSV с заголовками, разделитель – запятая (`,`).  
**Схема :**

| Колонка    | Тип      | Описание                   |
|------------|----------|----------------------------|
| `userId`   | integer  | Идентификатор пользователя |
| `movieId`  | integer  | Идентификатор фильма       |
| `rating`   | real     | Оценка                     |
| `timestamp`| integer  | Время выставления оценки   |

---

### `movies.csv`
Файл содержит информацию о фильмах.  
**Формат:** CSV с заголовками, разделитель – запятая (`,`).  
**Схема:**

| Колонка      | Тип      | Описание                             |
|--------------|----------|--------------------------------------|
| `movieId`    | integer  | Уникальный идентификатор фильма      |
| `title`      | text     | Название фильма и год выпуска        |
| `genres`     | text     | Список жанров через разделитель `\|` |

---

### `tags.csv`
Файл содержит теги, добавленные пользователями к фильмам.  
**Формат:** CSV с заголовками, разделитель – запятая (`,`).  
**Схема:**

| Колонка      | Тип      | Описание                   |
|--------------|----------|----------------------------|
| `userId`     | integer  | Идентификатор пользователя |
| `movieId`    | integer  | Идентификатор фильма       |
| `tag`        | text     | Текст тега                 |
| `timestamp`  | integer  | Время добавления           |

---

### `users.txt`
Файл с информацией о пользователях.  
**Формат:** текстовый файл с разделителем `|` (вертикальная черта).  
**Структура:**

| Поле         | Тип      | Описание                              |
|--------------|----------|---------------------------------------|
| `id`         | integer  | Уникальный идентификатор пользователя |
| `full_name`  | text     | Полное имя                            |
| `email`      | text     | Адрес электронной почты               |
| `gender`     | text     | Пол (`male`/`female`)                 |
| `birth_date` | text     | Дата рождения в формате ГГГГ-ММ-ДД    |
| `profession` | text     | Профессия (см. `occupation.txt`)      |

---

### `occupation.txt`
Справочник профессий.  
**Формат:** текстовый файл, каждая строка содержит одно название профессии.  

---

### `genres.txt`
Справочник жанров фильмов.  
**Формат:** текстовый файл, каждая строка содержит одно название жанра.  

---

### Дополнительные файлы, созданные в ходе работы

- **`ratings_count.txt`** – содержит минимальный и максимальный `userId` из `ratings.csv` и количество записей для каждого из них.  
  Формат: две строки вида `<userId> <количество>`.  
  *Пример:*  
  `1 232`  
  `99 53`

- **`sqlite.txt`** – содержит версию установленной СУБД SQLite и список доступных режимов вывода в утилите `sqlite3`.
