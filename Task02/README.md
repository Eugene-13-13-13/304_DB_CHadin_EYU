# Task02 — ETL для базы данных movies_rating

## Назначение

Каталог содержит утилиту для автоматической генерации SQL-скрипта и загрузки исходных данных в базу данных SQLite

---

Состав:

- `make_db_init.py` — утилита на Python 3, которая читает исходные файлы (`movies.csv`, `ratings.csv`, `tags.csv`, `users.txt`) и генерирует скрипт `db_init.sql` с командами `CREATE TABLE ...` и `INSERT INTO ...`
- `db_init.bat` — кроссплатформенный shell-скрипт, который запускает утилиту и применяет сгенерированный SQL к базе данных
- `dataset/` — каталог с исходными данными

---

## Требования к окружению

Для корректной работы `db_init.bat` на компьютере должны быть установлены:

1. **Python v.3** — интерпретатор для запуска `make_db_init.py`
   Команда должна быть доступна как `python3` или `python`
   Сторонние Python-пакеты не требуются — используются только модули стандартной библиотеки: csv, re, os

2. **SQLite 3** — утилита командной строки sqlite3 для применения сгенерированного SQL-скрипта к базе данных
